A single line of text — a home Wi-Fi router excusing itself for dropping the connection at the climax of a movie.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
